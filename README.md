# TkinterX Compiler

## Что это такое
Перед вами компилятор проектов для обычной библиотеки `tkinter` на Python. Вы спросите, для чего это нужно? Всё дело в том, что раньше создание проектов на этой библиотеке было немного неудобным, а сейчас вы просто пишете проект только из одного файла разметки `main.lua` и файлов логики `*.py`. Для вас это может показаться неудобным, так как всё было в одном файле, но поверьте, когда кода станет очень много, то размещать его так станет плохой практикой. И вот поэтому и был создан этот компилятор.

> [!NOTE]
> Данная программа компилирует код вашего проекта в код на языке Python, а также ищет модули, установленные в Python глобально, так что, для корректной работы компилятора, вам потребуется установить интерпретатор Python `3.13.x` и выше. Скачать интерпретатор можно [здесь](https://www.python.org)

> [!WARNING]
> За ошибки в вашем проекте и/или скомпилированном коде, вызванные неправильным написанием синтаксиса, мы ответственности НЕ НЕСЁМ! Если вы всё же обнаружили ошибки в работе самого компилятора, то пишите в раздел `Issues`.

## Как использовать компилятор
Компилятор является консольным. Это значит, что имеется поддержка ввода команд через консоль, но отсутствует графический интерфейс.

> [!WARNING]
> Важное напоминание: данный компилятор НЕ поддерживает запуск программ, он только производит их сборку.

Вот некоторые агрументы компилятора:

- `project_path` - тут вам нужно ввести путь к вашему проекту (к папке, не к файлу!), где находятся `main.lua` и остальные файлы;
- `-o, --output OUTPUT` - имя главного файла после компиляции (по умолчанию, это `program.py`);
- `-v, --verbose` - более подробное логирование всех действий.
- `-h --help` - показ всех аргументов

## Примеры кода
Вот наглядные примеры кода для сравнения:

### Без `TKX`
```python
import tkinter as tk

def say_hello():
    print("Привет из чистого Python!")

# Инициализация окна
root = tk.Tk()
root.title("Окно без TKX")
root.geometry("400x300")

# Создание виджетов
label = tk.Label(root, text="Добро пожаловать в обычный Tkinter")
label.pack(pady=10)

button = tk.Button(root, text="Нажми меня", command=say_hello)
button.pack(pady=20)

# Запуск
root.mainloop()
```

### Используя `TKX`

> [!NOTE]
> Главная разметка приложения пишется на `Lua`, а логика на `Python`, что может по началу быть не привычно.

1. #### main.lua
```lua
-- Настраиваем окно
Window("Окно с TKX", "400x300")

-- Подключаем файл логики Python
ImportPython("logic")

-- Создаем элементы интерфейса
Label("Добро пожаловать в tkx Framework!", "pady=10")
Button("Нажми меня", "pady=20", "cool.say_hello")
```

2. #### logic.py
```python
def say_hello():
    print("Привет из файла логики через TKX!")
```

3. #### Компиляция
Для запуска данной программы требуется её скомпилировать:
```cmd
tkx project_path -o program.py
```
