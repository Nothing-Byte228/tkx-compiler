# TkinterX Compiler

## Что это такое

Перед вами компилятор проектов для обычной библиотеки `tkinter` на Python. Вы спросите, для чего это нужно? Всё дело в том, что раньше создание проектов на этой библиотеке было немного неудобным, а сейчас вы просто пишете проект только из файла разметки `main.lua` и файлов логики `*.py`.
